# Agent Note: 禁用未披露的辅助出站流量

Status: implemented

[English](2026-08-20-disable-undisclosed-auxiliary-egress.md) | 中文

## 问题

已交付组合可以在用户选择的会话模型调用之外发起远程请求。首提示词标题提供方会在主轮次启动后把第一条人类消息发送给模型；自动压缩会在压力或上下文溢出后把会话上下文发送给摘要路由；`web_search` 会把模型选择的查询发送到独立的 DeepSeek Messages 端点。这些调用有日志记录并使用已配置的凭据，但默认挂载并不能证明用户已授权其目的、目的地或输入。

在全新 profile 中，遥测已经解析为 `DISABLED`，该模式下反馈只记录到本地会话日志。仓库中不存在随附的自动更新检查器。因此，其余默认辅助模型路径决定了全新 profile 的唯一远程内容流是否就是用户选择的会话请求。

## 决策

共享 base bundle 保持确定性的会话标题服务启用，并禁用 `session-title-llm`。它保留提供方无关的 Web 服务和稳定的 `web_search` 消费方，但禁用已交付的 `web-search-deepseek` 提供方。没有获得授权的提供方时，搜索尝试不会产生网络结果。部署需要显式选择启用任一提供方行，并披露该行描述的目的地和输入：标题生成接收第一条合格的人类提示词，搜索接收查询并发送到配置的 Anthropic 兼容 Messages 基址。

`dsh-compaction-basic` 在省略 `auto` 时解析为 `false`。base bundle 与每个完整的已交付 agent preset 也都明确写出 `auto: false`，使隐私选择在组合位置清晰可见。压缩服务与 `/compact` 命令仍保持挂载：人类可以主动请求一次摘要，但压力检查和上下文溢出恢复不会启动辅助调用。启用 `auto: true` 会授权自动摘要把回放的会话前缀发送到配置的摘要提供方／模型；若这些覆盖项为空，则发送到会话路由。

遥测行仍然挂载，并在全新 profile 中使用 `DISABLED` 模式；该模式不创建导出器，`/feedback` 保持本地。`DSH_TELEMETRY_MODE=FULL` 或 `FEEDBACK_ONLY` 仍是部署对已配置 OTLP 目的地的显式选择启用。任何已禁用路径都不会获得兼容 shim、隐式凭据触发或回退远程提供方。

组装后的 Web 反馈场景会启动真实 base 与 Web bundle 层，恰好运行一次由回放提供方支持的会话请求，观察回退 `session/title`，拒绝任何 `session/title-llm-request`，在禁用共享状态下记录 `/feedback`，并要求回放脚本被完整消费。base bundle 测试另行固定已禁用的标题和搜索行、已禁用的自动压缩，以及禁用遥测的表达式。各提供方专属测试继续覆盖已授权的标题、搜索、压缩和遥测路径。

## 考虑过的替代方案

**因为辅助调用使用所选凭据，所以保持默认启用。** 凭据只能证明宿主可以向端点认证；它并不授权第二种用途，也没有披露该用途会接收哪部分会话数据。便利性不能让额外数据流自动成为用户会话请求的一部分。

**完全删除辅助能力。** 显式授权的标题、搜索、压缩与遥测仍然有用。保留其提供方和消费方可以继续提供扩展 seam，而不会向全新 profile 授予远程流量。

**只为上下文溢出恢复保留自动压缩。** 溢出恢复仍会在第二次模型请求中发送会话上下文，并可能通过摘要配置改变目的地。让原始请求失败好过静默扩大出站范围；部署可以在披露后启用完整的自动策略。

**同时禁用手动 `/compact`。** 该命令是人类直接发起的操作，其文档化结果需要模型摘要。删除它不会加强无人值守时的默认行为，反而会丢弃一条主动恢复路径。它继续与自动压力和溢出 listener 保持区分。

**在本次变更中添加通用运行时 ask／allow 策略。** 机器可读的出站清单和中央运行时决策层属于 P1 执行设计。默认关闭提供方与 listener 可以修复眼前的 P0 泄漏，同时避免引入可能被后续传输绕过的不完整策略词汇。

## 验证

- base patch 测试固定 `session-title-llm` 与 `web-search-deepseek` 为禁用状态、`compaction-basic.config.auto` 为 false，以及全新环境下遥测模式为 `DISABLED`。
- 压缩配置测试固定省略时 `auto: false`，并要求自动压力和溢出场景显式设置 `auto: true`。
- 无密钥的组装 Web 场景固定一次会话请求、回退标题处理、不存在标题模型请求，以及在禁用共享状态下本地记录反馈。
- 已授权的 Web 搜索组装场景会显式重新启用提供方，并提供 loopback Messages 目的地；聚焦的提供方测试继续保留其他显式调用路径。

## 后果

全新 profile 不再获得自动模型优化标题、自动上下文压力恢复和即刻可用的 Web 搜索。它们仍保留本地回退标题、主动手动压缩、稳定的 Web 工具 schema、本地反馈，以及所选的会话模型调用。模型仍可能在没有授权提供方时看到 `web_search`，并在调用后收到提供方不可用结果。

此变更建立的是安全默认值，而不是最终授权系统。它不会清点每种传输、提供交互式审批、把反馈上传与会话共享分离，也不会在产品设置中独立显示辅助调用。这些仍属于 P1 工作。若在没有披露的情况下重新启用提供方或 `auto`，它属于部署策略错误，而不是产品的隐式默认行为。
