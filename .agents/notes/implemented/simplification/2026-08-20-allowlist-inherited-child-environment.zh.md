# Agent Note: 对继承的子进程环境采用允许列表

Status: implemented

[English](2026-08-20-allowlist-inherited-child-environment.md) | 中文

## 问题

本地受管子进程曾继承父进程中除名称匹配 `KEY`、`PASSWORD`、`SECRET` 或 `TOKEN` 以及受管 `DSH_*` 命名空间以外的所有环境变量。这种启发式规则会遗漏名称无关的秘密，并把 `HOME`、产品配置路径、代理设置、项目元数据和任意部署状态转发给模型 shell 与进程外工具。拒绝列表无法建立隐私目标所需的保证，即原始秘密和私有环境提示默认留在模型控制的进程之外。

## 决策

共享的 `scrubbedParentEnv()` 基底只保留普通进程运行所需的变量：命令查找（`PATH`、`PATHEXT`、`COMSPEC`）、操作系统启动（`SYSTEMROOT`、`WINDIR`）、区域设置（`LANG`、`LANGUAGE`、`LC_*`）、终端行为（`TERM`、`NO_COLOR`）、时区（`TZ`）和临时目录（`TEMP`、`TMP`、`TMPDIR`）。POSIX 上精确匹配名称，Windows 上不区分大小写。主目录与配置路径、代理、凭据、`DSH_*` 和任意部署值都不会进入该基底。

显式子进程 `env` 仍是受信任 Host 授权，并在该基底之后合并。子进程操作需要时，消费方可以有意提供 API 密钥、端点、主目录、产品配置路径、代理或当前 `DSH_*` 事实。受管 shell 的 `dshEnv` 值最后合并，因此普通插件环境无法顶掉当前 Harness 事实。

本地普通子进程与终端子进程实现共享该基底。由 SDK 管理的 DSH 与 Claude Code subagent 传输、MCP stdio 传输、Web 浏览器 opener 和 LSP 辅助逻辑在其 spawn 无法经由 `ctx.subprocess` 时应用同一个导出函数。E2B 提供方仍是独立的远程执行环境：宿主环境变量绝不会进入其中，而它的沙箱默认环境发现与替换限制保留自身策略和后续工作。

本决策取代 stdin／环境、子进程 seam、ACP 后端、PTY、MCP、SDK subagent、产品 subagent 与启动环境记录中的凭据名称清理部分。那些记录继续拥有更广泛的 API、生命周期行为与提供方决策。

## 测试

Service Definition 测试固定保留类别，并证明 `HOME`、任意元数据、凭据和环境中的 `DSH_*` 值均缺失。本地进程测试覆盖普通与终端 spawn、显式授权、tombstone 和 Windows 不区分大小写的替换。ACP、DSH SDK、Claude Code、MCP、LSP、Web opener 与完整循环 bash 测试覆盖各自拥有的组合路径。组装后的无密钥 shell 快照记录 `HOME`、任意私有元数据路径与私有会话日志位置均未设置，而当前受管 shell 事实仍然存在。

## 考虑过的替代方案

**扩展秘密名称正则表达式。** 拒绝，因为有限的子串集合无法识别每个秘密、私有路径、代理或部署提示，每一种新命名约定都会重新打开泄露。

**传递空环境。** 拒绝，因为裸可执行文件查找与受支持操作系统需要少量操作性变量；区域设置、终端、时区和获准的临时存储也会影响确定性的子进程行为。

**让每个消费方拥有自己的允许列表。** 拒绝，因为并行的策略副本会漂移。拥有 SDK 管理 spawn 的消费方导入本地提供方所用的同一个纯函数。

**隐式保留原生产品主目录与端点。** 拒绝，因为这会让产品便利性静默恢复广泛的宿主发现。产品提供方会记录原生身份验证或用户配置所需的显式 `env` 授权。

## 影响

受管本地子进程不再继承 `HOME`、`XDG_*`、代理变量、`SSH_AUTH_SOCK`、提供方端点、任意项目变量或未知秘密名称。预发布配置若依赖环境中的用户主目录、原生身份验证、端点、代理或部署元数据，必须在所属插件的 `env` 配置中授予所需条目。

本变更不会约束文件系统读取、检查显式授予的值、限制继承的文件描述符，也不会改变远程 E2B 沙箱默认值。保留的操作性变量仍可能公开有限的平台、区域设置、时区、终端和临时目录信息。目标限定的网络授权与内核强制文件系统读取根目录仍是独立隐私工作。
