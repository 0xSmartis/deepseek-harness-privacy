# Agent Note: 不在模型 shell 环境中公开私有路径

Status: implemented

[English](2026-08-20-keep-private-paths-out-of-model-shells.md) | 中文

## 问题

受管理的 shell 环境曾向每个由模型控制的 shell 进程公开 Harness 主目录绝对路径 `DSH_HOME` 与 JSONL 会话日志目标 `DSH_SESSION_JSONL`。这些值不是凭据，但会点名文件系统策略本应隐藏的私有存储。公开这些值会直接向不受信任命令指明会话历史、凭据存储、设置、附件和其他用户状态的位置，并使隐私完全依赖每个进程沙箱后端都能拒绝后续读取。

## 决策

默认 `ctx.shellEnv` 注册表只贡献 `DSH_SHELL=1` 与会话作用域的 `DSH_SESSION_ID`。它不解析 Harness 主目录或会话持久化，也没有主目录配置。本地子进程实现会继续先移除所有继承的 `DSH_*` 值，再应用当前受管理快照，因此环境中的 `DSH_HOME`、`DSH_SESSION_JSONL` 与嵌套 Harness 的陈旧值均保持缺失。

`SessionPersistence.locate()` 仍供钩子桥接等受信任 Host 消费方使用。模型控制的 shell 不会从该查询获得存储位置。注册表仍接受受信任进程内插件的显式贡献；根据插件信任假设，这类贡献属于有意的 Host 决定，而不是默认的环境泄露。

本决策部分取代[会话环境决策](../feature/2026-07-10-agent-session-identity-and-log-location.md)中向模型 shell 公开位置的部分。该记录继续拥有逐次执行注册表、会话标识、持久化定位器与钩子语义。[项目会话目录](../architecture/2026-07-24-project-session-directories.md)继续通过 Host 定位器公开 transcript 路径，而不是通过子进程变量公开。广泛的文件系统读取约束仍是独立要求；移除位置提示并不声称 agent 猜到的路径无法访问。

## 测试

注册表与请求录制测试固定两个内置值以及默认 contributor 为空。bash 与 pwsh 测试覆盖前台、后台、无 agent 和父子收集。完整循环 bash 集成会在挂载真实 JSONL 持久化后端的同时提供环境 `DSH_HOME` 与 `DSH_SESSION_JSONL`；子进程观察到两者均未设置，而 Host 仍可定位并刷写会话日志。无密钥快照记录组装后的 shell 结果。

## 考虑过的替代方案

**保留路径并依赖文件系统约束。** 拒绝，因为公开敏感目标会放大不必要的权限，并会让一个后端缺口或一次获批的广泛读取直接变成对私有状态的访问。

**用面向模型的会话信息工具取代路径。** 拒绝，因为当前模型 shell 用例没有需要 transcript 位置的必要操作。未来有界的 Host 操作可以定义自己的授权和结果，无需重新引入通用路径查询器。

**移除所有受管理 shell 事实。** 拒绝，因为 `DSH_SHELL` 是无害的执行标记，而会话作用域 id 支持当前会话内关联，不会点名私有存储位置，也不会创建跨会话用户标识符。

**永久保留所有原有键。** 拒绝，因为受信任进程内插件已经位于 Host 信任边界内，并可能有意定义部署专用事实。隐私默认值移除内置贡献，但不会假装能够约束已安装的 Host 代码。

## 影响

模型控制的 shell 无法从默认 `DSH_*` 变量发现 Harness 主目录或活动 transcript 目标，即使父进程中存在这些名称也是如此。Host 钩子保留精确 transcript 位置。预发布阶段在模型 shell 调用中使用 `DSH_HOME` 或 `DSH_SESSION_JSONL` 的脚本必须改用显式授权的 Host 能力或用户提供的路径。

本变更减少路径泄露，但不代表文件系统约束已经完整：命令仍可能推断或猜测路径，普通非 `DSH_*` 环境变量仍遵循子进程策略，受信任插件也可以显式添加受管理事实。内核强制的读取根目录与作用域文件系统授权仍属于独立工作。
